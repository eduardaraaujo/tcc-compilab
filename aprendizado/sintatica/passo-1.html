Gramáticas (GLC)Derivação à esquerda

ATIVIDADE GUIADA

Como a gramática inicia a análise?

Uma GLC descreve quais sequências de tokens formam estruturas válidas. Observe o código de referência e identifique a produção que descreve sua declaração.

REFERÊNCIA DO EXEMPLO

Código e gramática de referência

O analisador léxico já separou o código em tokens. Agora o analisador sintático precisa reconhecer como eles se combinam.

Código de referência 
let total = preco * 2;
Tokens reconhecidos 
let id = id * num ;

Este é o exemplo usado nas atividades guiadas. A gramática também permite outros operadores e mais de uma declaração; esses casos poderão ser experimentados no laboratório.

Gramática completa do exemplo 
S  → D L
L  → D L | ε
D  → 'let' id '=' E ';'
E  → T E'
E' → '+' T E' | '-' T E' | ε
T  → F T'
T' → '*' F T' | '/' F T' | ε
F  → '(' E ')' | '-' F | id | num

S é o símbolo inicial; D reconhece uma declaração e L → D L | ε permite outras declarações ou encerra a lista. E, T e F descrevem expressões. id e num são categorias de tokens.

Qual a diferença entre terminal e não terminal?

Terminais são símbolos reconhecidos na entrada, como let, id, =, * e ;. Não terminais, como E, são estruturas expandidas pelas produções da gramática.

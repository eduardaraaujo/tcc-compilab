ⓘCom um não terminal no topo, o parser consulta a tabela. Com um terminal igual ao próximo token, ele consome o token.
Gramática completa usada na simulação 
S  → D L
L  → D L | ε
D  → 'let' id '=' E ';'
E  → T E'
E' → '+' T E' | '-' T E' | ε
T  → F T'
T' → '*' F T' | '/' F T' | ε
F  → '(' E ')' | '-' F | id | num

A primeira ação está visível.

A simulação usa a declaração let total = preco * 2;, representada pelas categorias let id = id * num ;. Quando chega a L, o parser escolhe L → ε, pois a entrada terminou. É uma demonstração fixa, não um parser para entradas arbitrárias.

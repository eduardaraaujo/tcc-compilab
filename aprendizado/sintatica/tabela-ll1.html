REFERÊNCIA PARA A DECISÃO

Como escolher uma produção?

Gramática completa — símbolo inicial S 
S  → D L
L  → D L | ε
D  → 'let' id '=' E ';'
E  → T E'
E' → '+' T E' | '-' T E' | ε
T  → F T'
T' → '*' F T' | '/' F T' | ε
F  → '(' E ')' | '-' F | id | num

Para a questão, use FIRST(T') = { *, /, ε } e FOLLOW(T') = { +, -, ), ; }. Observe que + está em FOLLOW(T'), então usamos a produção que gera ε.

ⓘUma produção ocupa as colunas de seus símbolos em FIRST. Se ela puder gerar ε, também ocupa as colunas de FOLLOW do não terminal.

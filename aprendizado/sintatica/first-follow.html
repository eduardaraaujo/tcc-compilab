REFERÊNCIA DA DISCIPLINA

Gramática de referência

Usaremos a mesma gramática nas questões de FIRST/FOLLOW, na construção da tabela preditiva e na simulação com pilha.

S  → D L
L  → D L | ε
D  → 'let' id '=' E ';'
E  → T E'
E' → '+' T E' | '-' T E' | ε
T  → F T'
T' → '*' F T' | '/' F T' | ε
F  → '(' E ')' | '-' F | id | num
ⓘ FIRST observa como uma derivação pode começar. FOLLOW observa o que pode aparecer imediatamente depois de um não-terminal. ε não é token; $ marca o fim da entrada.

Definição e regras de FIRST

Definição de PRIMEIRO (FIRST)

PRIMEIRO(α) é o conjunto de terminais que começam as cadeias derivadas a partir de α.

Se α ⇒* ε então ε também está em PRIMEIRO(α).

α pode ser qualquer cadeia de símbolos gramaticais.

Como calcular Primeiro (First)?

Para calcular PRIMEIRO(X) para todos os símbolos gramaticais X, aplicar as regras até que nenhum terminal ou ε possa ser adicionado a qualquer conjunto PRIMEIRO.

  1. Se X for um terminal, então PRIMEIRO(X) = {X}.
  2. Se X → ε for uma produção, adicionar ε a PRIMEIRO(X).
  3. Se X for um não-terminal e X → Y1Y2...Yk for uma produção, se para algum i, todos Y1Y2...Yi-1 derivam ε, então PRIMEIRO(Yi) está em PRIMEIRO(X).
    Se todo Yj (j=1, 2,..., k) deriva ε, então ε está em PRIMEIRO(X).

Definição e regras de FOLLOW

Definição de SEGUINTE (FOLLOW)

SEGUINTE(A), para o não-terminal A, é o conjunto de terminais a que podem aparecer imediatamente à direita de A em alguma forma sentencial, isto é, o conjunto de terminais a tais que exista uma derivação da forma

S ⇒* α A a β para algum α e β.

Como calcular Seguinte (Follow)?

Para calcular SEGUINTE(A) para todos os não-terminais A, aplicar as regras até que nada mais possa ser adicionado a qualquer conjunto SEGUINTE.

  1. Se S for o símbolo inicial da gramática e $ for o marcador de fim de sentença, então $ está em SEGUINTE(S).
  2. Se existir uma produção A → α B β, então tudo em PRIMEIRO(β), exceto ε, é adicionado em SEGUINTE(B).
  3. Se existir uma produção A → α B [ou uma produção A → α B β onde PRIMEIRO(β) contém ε (isto é, β ⇒* ε)], então todos os terminais que estiverem em SEGUINTE(A) estarão em SEGUINTE(B).

CONCLUSÃO DAS DUAS QUESTÕES

Conjuntos FIRST e FOLLOW da gramática completa

Você encontrou FIRST(E') = { +, -, ε } e FOLLOW(E') = { ), ; }. Como E' aparece no fim de E → T E', ele herda FOLLOW(E). A gramática também aceita uma lista de declarações por meio de L.

Não terminal FIRST FOLLOW
S{ let }{ $ }
L{ let, ε }{ $ }
D{ let }{ let, $ }
E{ id, num, -, ( }{ ), ; }
E'{ +, -, ε }{ ), ; }
T{ id, num, -, ( }{ +, -, ), ; }
T'{ *, /, ε }{ +, -, ), ; }
F{ id, num, -, ( }{ +, -, *, /, ), ; }

FOLLOW não inclui ε. Os conjuntos apresentados são fixos para esta gramática didática; não são calculados a partir de entradas editáveis.

ATIVIDADE GUIADA — FIRST

O que pode começar E'?

FIRST reúne os terminais que podem iniciar uma derivação. Incluímos ε quando o não terminal pode gerar a cadeia vazia.

ATIVIDADE GUIADA — FOLLOW

O que pode vir depois de E'?

FOLLOW reúne os terminais que podem aparecer depois de um não terminal. Como S é inicial, FOLLOW(S) = { $ }. Em S → D L, D pode ser seguido por outra declaração (let) ou pelo fim do programa ($); por isso, FOLLOW(D) = { let, $ }. Já E aparece antes de ; em D e antes de ) em F.

GRAMÁTICA DE REFERÊNCIA

Uma gramática para LL(1)

Usaremos a mesma gramática no cálculo de conjuntos, na tabela preditiva e na simulação com pilha.

S  → D L
L  → D L | ε
D  → 'let' id '=' E ';'
E  → T E'
E' → '+' T E' | '-' T E' | ε
T  → F T'
T' → '*' F T' | '/' F T' | ε
F  → '(' E ')' | '-' F | id | num
ⓘFIRST: como uma derivação pode começar. FOLLOW: o que pode vir imediatamente depois do não terminal. ε não é um token; $ marca o fim da entrada.
CONCLUSÃO DAS DUAS QUESTÕES

Conjuntos FIRST e FOLLOW da gramática completa

Você encontrou FIRST(E') = { +, -, ε } e FOLLOW(E') = { ), ; }. Como E' aparece no fim de E → T E', ele herda FOLLOW(E). A gramática também aceita uma lista de declarações através de L.

Não terminal FIRST FOLLOW
S { let } { $ }
L { let, ε } { $ }
D { let } { let, $ }
E { id, num, -, ( } { ), ; }
E' { +, -, ε } { ), ; }
T { id, num, -, ( } { +, -, ), ; }
T' { *, /, ε } { +, -, ), ; }
F { id, num, -, ( } { +, -, *, /, ), ; }

FOLLOW não inclui ε. Os conjuntos apresentados são fixos para esta gramática didática; não são calculados a partir de entradas editáveis.
